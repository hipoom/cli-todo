## 技术实现

在 TodoShellHandler.kt 的 onHandle 方法中，在收集命令的逻辑中，添加以下代码：

```kotlin
// 添加 cmdMappings 中的映射
cmdMappings.mappings.forEach {
    commands.add(it.quick)
}
```

这样，所有在 cmdMappings 中定义的映射都会被添加到字符串补全列表中，用户在输入命令时就能看到这些映射的补全提示。
