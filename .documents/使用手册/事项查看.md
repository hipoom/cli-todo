## 1.2 基本展示命令

### 1.2.1 `show` 命令

最基本的展示命令，用于显示当前工作区中的所有事项。

**命令格式：**

```bash
show
```

**执行结果示例：**

```
[1] [◌] |-- 项目 A
[2] [~] |   |-- 任务 1: 完成数据库设计
[3] [◌] |   `-- 任务 2: 编写 API 接口
[4] [✔] `-- 项目 B 👤 张三 🏷️ 后端

没有事项~
```

**显示效果说明：**

- 事项以树状结构展示，使用 `|--` 和 `` `-- `` 表示层级关系
- 每个事项显示：ID、状态、内容、负责人、标签、截止时间等信息
- 已完成的事项会以绿色显示（状态为 `✔`）
- 折叠的事项会显示 `[+]` 标记
- 如果没有任何事项，会显示"没有事项\~"

## 1.3 展示选项配置

### 1.3.1 显示/隐藏已完成事项

控制是否在列表中显示状态为"已完成"的事项。

**启用显示已完成事项：**

```bash
show --enable-done
```

**执行结果：**

```
已启用显示已完成事项

[1] [◌] |-- 进行中的任务
[2] [✔] `-- 已完成的任务
```

**禁用显示已完成事项（默认）：**

```bash
show --disable-done
```

**执行结果：**

```
已禁用显示已完成事项

[1] [◌] `-- 进行中的任务
```

### 1.3.2 显示/隐藏已删除事项

控制是否在列表中显示状态为"已删除"的事项。

**启用显示已删除事项：**

```bash
show --enable-deleted
```

**执行结果：**

```
已启用显示已删除事项

[1] [◌] |-- 正常任务
[2] [×] `-- 已删除的任务
```

**禁用显示已删除事项（默认）：**

```bash
show --disable-deleted
```

**执行结果：**

```
已禁用显示已删除事项

[1] [◌] `-- 正常任务
```

### 1.3.3 显示/隐藏事项 ID

控制是否在列表中显示事项的唯一标识符。

**启用显示事项 ID（默认）：**

```bash
show --enable-id
```

**执行结果：**

```
已启用显示事项 ID

[1] [◌] |-- 任务 A
[2] [~] `-- 任务 B
```

**禁用显示事项 ID：**

```bash
show --disable-id
```

**执行结果：**

```
已禁用显示事项 ID

[◌] |-- 任务 A
[~] `-- 任务 B
```

**显示格式说明：**

- ID 会根据最大 ID 值自动对齐
- 例如：`[1]`、`[ 2]`、`[ 10]`

### 1.3.4 显示/隐藏事项状态

控制是否在列表中显示事项的当前状态图标。

**启用显示状态（默认）：**

```bash
show --enable-status
```

**执行结果：**

```
已启用显示状态

[1] [◌] |-- 新建任务
[2] [~] |-- 进行中任务
[3] [✔] `-- 已完成任务
```

**禁用显示状态：**

```bash
show --disable-status
```

**执行结果：**

```
已禁用显示状态

[1] |-- 新建任务
[2] |-- 进行中任务
[3] `-- 已完成任务
```

**状态图标说明：**

| 状态        | 图标  | 说明   |
| --------- | --- | ---- |
| `new`     | `◌` | 新建事项 |
| `doing`   | `~` | 进行中  |
| `done`    | `✔` | 已完成  |
| `deleted` | `×` | 已删除  |

### 1.3.8 启动时自动展示

```
[3] [◌] |   `-- 子任务 2
[4] [✔] `-- 项目 B
```

## 1.4 聚焦功能

聚焦功能允许你将视图聚焦到某个特定事项及其子事项上，方便专注于某个项目或任务的细节。

### 1.4.1 设置聚焦

**命令格式：**

```bash
focus -i <id>
```

**示例：聚焦到 ID 为 5 的事项**

```bash
focus -i 5
```

**执行结果：**

```
已聚焦到事项 [5]

[5] [◌] 项目 A
[6] [~] |-- 任务 1: 完成数据库设计
[7] [◌] |   |-- 子任务 1.1
[8] [◌] |   `-- 子任务 1.2
[9] [✔] `-- 任务 2: 编写 API 接口
```

**说明：**

- 聚焦后，只显示该事项及其所有子事项
- 其他事项会被隐藏
- 适合深入查看某个项目的详细内容

### 1.4.2 清除聚焦

**命令格式：**

```bash
focus -c
```

**执行结果：**

```
已清除聚焦

[1] [◌] |-- 项目 A
[2] [~] |   |-- 任务 1
[3] [◌] `-- 任务 2
[4] [✔] `-- 项目 B
```

**说明：**

- 清除聚焦后，恢复显示所有事项
- 返回到全局视图模式

### 1.4.3 聚焦到父事项

**命令格式：**

```bash
focus -p
```

**执行结果示例：**

假设当前聚焦在 ID 为 7 的子任务上：

```
当前聚焦: [7] 子任务 1.1

执行 focus -p 后：

已聚焦到父事项 [5]

[5] [◌] 项目 A
[6] [~] |-- 任务 1
[7] [◌] |   |-- 子任务 1.1
[8] [◌] |   `-- 子任务 1.2
[9] [✔] `-- 任务 2
```

**边界情况：**

如果当前聚焦的是根事项：

```
当前正在聚焦的事项，没有父级事项了.
```

### 1.4.4 聚焦到相邻事项

**聚焦到下一个同级事项：**

```bash
focus -d
```

**执行结果示例：**

```
当前聚焦: [6] 任务 1

执行 focus -d 后：

已聚焦到 [9] 任务 2

[9] [✔] 任务 2: 编写 API 接口
```

**聚焦到上一个同级事项：**

```bash
focus -u
```

**执行结果示例：**

```
当前聚焦: [9] 任务 2

执行 focus -u 后：

已聚焦到 [6] 任务 1

[6] [~] 任务 1: 完成数据库设计
[7] [◌] |-- 子任务 1.1
[8] [◌] `-- 子任务 1.2
```

**边界情况：**

```
往上没有平级事项了~

# 或

往下没有平级事项了~
```

**使用场景：**

- 快速浏览同级事项
- 在子事项之间导航
- 配合其他命令进行批量操作

## 1.5 固定事项

固定功能允许你将重要的事项固定显示在列表顶部，方便快速访问。

### 1.5.1 添加固定

**命令格式：**

```bash
pin -i <id>
```

**示例：固定 ID 为 1 和 2 的事项**

```bash
pin -i 1,2
```

**执行结果：**

```
已固定事项: [1], [2]

-----
[1] [◌] 重要任务 A
[2] [~] 重要任务 B
-----
[3] [◌] |-- 普通任务 C
[4] [✔] `-- 普通任务 D
```

**说明：**

- 固定的事项会显示在列表顶部
- 以分隔线 `-----` 与普通事项区分
- 可以同时固定多个事项，使用逗号分隔 ID

### 1.5.2 查看固定事项

**命令格式：**

```bash
pin -s
```

**执行结果：**

```
-----
[1] [◌] 重要任务 A
[2] [~] 重要任务 B
-----
```

**说明：**

- 只显示固定的事项
- 不显示其他普通事项
- 方便快速查看重要事项

### 1.5.3 取消固定

**命令格式：**

```bash
pin -u <id>
```

**示例：取消固定 ID 为 1 的事项**

```bash
pin -u 1
```

**执行结果：**

```
已取消固定事项: [1]

-----
[2] [~] 重要任务 B
-----
[3] [◌] |-- 普通任务 C
[4] [✔] `-- 普通任务 D
```

**显示效果说明：**

- 固定的事项会显示在列表顶部
- 以白色背景高亮显示（根据当前样式）
- 与普通事项用分隔线隔开
- 固定的事项不会因为过滤条件而被隐藏

## 1.6 虚拟视图

虚拟视图功能允许你创建自定义的事项集合，方便分组查看不同场景的事项。

### 1.6.1 创建视图

**命令格式：**

```bash
view -c <视图名称>
```

**示例：创建名为 "sprint-1" 的视图**

```bash
view -c sprint-1
```

**执行结果：**

```
成功创建虚拟视图: sprint-1
```

**说明：**

- 视图名称建议使用有意义的命名
- 例如：sprint-1、today、bugfix、release 等
- 创建后需要添加事项到视图中

### 1.6.2 切换视图

**命令格式：**

```bash
view <视图名称>
```

**示例：切换到 "sprint-1" 视图**

```bash
view sprint-1
```

**执行结果：**

```
已切换到虚拟视图: sprint-1
已清除聚焦

[1] [◌] |-- Sprint 1 任务 A
[2] [~] `-- Sprint 1 任务 B
```

**说明：**

- 切换视图后会自动显示该视图中的事项
- 只显示添加到该视图的事项
- 切换视图时会自动清除聚焦状态

### 1.6.3 添加事项到视图

**添加事项到当前视图：**

```bash
view -a <id>
```

**示例：将 ID 为 1,2,3 的事项添加到当前视图**

```bash
view -a 1,2,3
```

**执行结果：**

```
操作结果: 成功添加 3 个事项到视图 'sprint-1'，0 个事项已存在
```

**添加事项到指定视图：**

```bash
view -a <id> -v <视图名称>
```

**示例：将 ID 为 1 的事项添加到 "sprint-1" 视图**

```bash
view -a 1 -v sprint-1
```

**执行结果：**

```
操作结果: 成功添加 1 个事项到视图 'sprint-1'，0 个事项已存在
```

**重复添加的情况：**

```bash
view -a 1,2 -v sprint-1
```

**执行结果：**

```
操作结果: 成功添加 0 个事项到视图 'sprint-1'，2 个事项已存在
```

### 1.6.4 列出所有视图

**命令格式：**

```bash
view --list
```

**执行结果：**

```
虚拟视图列表:
1. sprint-1 (当前) (包含 5 个事项)
2. sprint-2 (包含 3 个事项)
3. today (包含 2 个事项)
4. bugfix (包含 8 个事项)
```

**说明：**

- 显示所有已创建的虚拟视图
- 标记当前正在使用的视图
- 显示每个视图包含的事项数量

### 1.6.5 退出视图模式

**命令格式：**

```bash
view --exit
```

**执行结果：**

```
已退出虚拟视图模式

[1] [◌] |-- 项目 A
[2] [~] |   |-- 任务 1
[3] [◌] `-- 任务 2
[4] [✔] `-- 项目 B
...
```

**说明：**

- 退出后恢复显示所有事项
- 视图本身不会被删除，可以随时再次切换

### 1.6.6 删除视图

**命令格式：**

```bash
view --delete <视图名称>
```

**示例：删除 "sprint-1" 视图**

```bash
view --delete sprint-1
```

**执行结果：**

```
成功删除虚拟视图: sprint-1
```

**说明：**

- 删除视图不会删除视图中的事项
- 只是删除视图的定义
- 如果当前正在使用该视图，会自动退出视图模式

## 1.7 分组显示模式

分组显示模式控制事项的展示方式，可以选择按树状结构或按负责人分组。

### 1.7.1 按树状结构显示（默认）

**命令格式：**

```bash
group -t
```

**执行结果：**

```
已切换到树状结构显示模式

[1] [◌] |-- 项目 A
[2] [~] |   |-- 任务 1: 完成数据库设计
[3] [◌] |   `-- 任务 2: 编写 API 接口
[4] [✔] `-- 项目 B
```

**显示效果说明：**

- 按父子关系以树状结构显示
- 使用 `|--` 表示中间子项
- 使用 `` `-- `` 表示最后一个子项
- 使用 `|` 和 `.` 表示缩进层级

### 1.7.2 按负责人分组显示

**命令格式：**

```bash
group -o
```

**执行结果：**

```
已切换到按负责人分组显示模式

👤 张三:
[1] [◌] |-- 任务 A
[2] [~] `-- 任务 B

👤 李四:
[3] [◌] |-- 任务 C
[4] [✔] `-- 任务 D

👤 未指定:
[5] [◌] `-- 任务 E
```

**显示效果说明：**

- 按负责人分组显示事项
- 每组显示负责人图标和名称
- 没有负责人的事项归类到"未指定"组
- 同一事项如果有多个负责人，会在多个组中显示

## 1.8 样式配置

样式配置控制事项显示的颜色和风格，支持浅色和深色主题。

### 1.8.1 查看可用样式

**命令格式：**

```bash
style --list
```

**执行结果：**

```
可用样式列表:
* light (当前)
  dark
  custom-blue
```

**说明：**

- `*` 标记当前使用的样式
- 显示所有内置和自定义样式

### 1.8.2 选择样式

**命令格式：**

```bash
style --choose
```

**执行结果：**

```
请选择样式:
1. light
2. dark
3. custom-blue

请输入编号: 2

已切换到样式: dark
```

**说明：**

- 交互式选择样式
- 输入编号即可切换
- 切换后立即生效

### 1.8.3 查看当前样式详情

**命令格式：**

```bash
style --details
```

**执行结果：**

```
当前样式: light

样式配置:
- 固定事项文字颜色: RGB(0, 0, 0)
- 固定事项背景颜色: RGB(255, 255, 255)
- 次要文字颜色: RGB(100, 100, 100)
- 评论背景颜色: RGB(250, 250, 250)
- 提示文字颜色: RGB(200, 200, 200)
```

### 1.8.4 创建自定义样式

**命令格式：**

```bash
style --create <样式名称>
```

**示例：创建名为 "my-theme" 的样式**

```bash
style --create my-theme
```

### 1.9.2 展示配置项说明

| 配置项                       | 说明         | 默认值     |
| ------------------------- | ---------- | ------- |
| `show.needShowDeleted`    | 是否显示已删除事项  | `false` |
| `show.needShowDone`       | 是否显示已完成事项  | `false` |
| `show.needShowId`         | 是否显示事项 ID  | `true`  |
| `show.needShowStatus`     | 是否显示事项状态   | `true`  |
| `show.needShowOwner`      | 是否显示负责人    | `true`  |
| `show.needShowLabel`      | 是否显示标签     | `true`  |
| `show.useAlignMode`       | 是否使用高级对齐模式 | `false` |
| `show.needShowDeadline`   | 是否显示截止时间   | `true`  |
| `launch.needShowOnLaunch` | 启动时是否自动展示  | `true`  |

### 1.9.3 高级对齐模式

高级对齐模式用于在支持等宽中文字符的终端中实现更好的对齐效果。

**启用高级对齐模式后的显示效果：**

```
[1] [◌] |-- 项目 A                  👤 张三  🏷️ 前端
[2] [~] |   |-- 任务 1: 完成设计    👤 李四
[3] [◌] |   `-- 任务 2: 编写接口    👤 王五  🏷️ 后端
[4] [✔] `-- 项目 B                  👤 张三
```

**说明：**

- 仅在终端字体能够严格保证一个中文字符宽度是英文字符两倍时使用
- 大多数现代终端默认支持此模式
- 如果对齐出现问题，请禁用此选项

## 1.10 快捷使用技巧

### 1.10.1 组合命令

展示命令可以与其他命令组合使用，实现快速操作：

**聚焦到某个事项后立即显示：**

```bash
focus -i 5
```

**执行结果：**

```
已聚焦到事项 [5]

[5] [◌] 项目 A
[6] [~] |-- 任务 1
[7] [◌] `-- 任务 2
```

**切换分组模式后立即显示：**

```bash
group -o
```

**执行结果：**

```
已切换到按负责人分组显示模式

👤 张三:
[1] [◌] |-- 任务 A
...
```

**切换视图后立即显示：**

```bash
view sprint-1
```

**执行结果：**

```
已切换到虚拟视图: sprint-1

[1] [◌] |-- Sprint 1 任务 A
...
```

### 1.10.2 常用工作流

**场景一：查看今日任务**

```bash
# 步骤 1: 切换到今日视图
view today
```

**执行结果：**

```
已切换到虚拟视图: today

[1] [~] |-- 今日任务 A
[2] [◌] `-- 今日任务 B
```

如果视图不存在：

```bash
# 步骤 1: 创建视图
view -c today
```

**执行结果：**

```
成功创建虚拟视图: today
```

```bash
# 步骤 2: 添加事项到视图
view -a 1,2,3 -v today
```

**执行结果：**

```
操作结果: 成功添加 3 个事项到视图 'today'，0 个事项已存在
```

**场景二：查看项目进度**

```bash
# 步骤 1: 显示所有事项（包括已完成）
show --enable-done
```

**执行结果：**

```
已启用显示已完成事项

[1] [◌] |-- 项目 A
[2] [~] |   |-- 任务 1
[3] [✔] |   `-- 任务 2
[4] [✔] `-- 项目 B
```

```bash
# 步骤 2: 聚焦到项目根事项
focus -i 1
```

**执行结果：**

```
已聚焦到事项 [1]

[1] [◌] 项目 A
[2] [~] |-- 任务 1
[3] [✔] `-- 任务 2
```

**场景三：按负责人分配任务**

```bash
# 步骤 1: 切换到按负责人分组模式
group -o
```

**执行结果：**

```
已切换到按负责人分组显示模式

👤 张三:
[1] [◌] |-- 任务 A
[2] [~] `-- 任务 B

👤 李四:
[3] [◌] |-- 任务 C

👤 未指定:
[4] [◌] `-- 任务 D
```

```bash
# 步骤 2: 查看各负责人的任务情况
show
```

**场景四：快速浏览重要事项**

```bash
# 步骤 1: 固定重要事项
pin -i 1,5,10
```

**执行结果：**


```bash
pin -s
```

**执行结果：**

```
-----
[1] [◌] 重要任务 A
```
