# 配置系统文档

## 1. 概述

cli-todo 项目采用三层配置架构，分别为进程级别、App 级别和 Workspace 级别。每层配置有不同的生命周期和存储方式，适用于不同的使用场景。

## 2. 配置层级架构

### 2.1 架构图

```
┌─────────────────────────────────────────────────────────────────┐
│                        进程级别配置                              │
│  (ProcessData - 内存存储，进程结束后消失)                         │
│  - current_workspace: 当前工作空间                               │
│  - currentWorkspaceDataRepository: 当前工作空间数据仓库           │
│  - currentCmdPrefix: 当前命令前缀                                │
└─────────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────────┐
│                        App 级别配置                              │
│  (PersistentData - 数据库存储，跨工作空间共享)                    │
│  - currentWorkspace: 当前工作空间别名                            │
│  - styles: 样式配置                                              │
│  - text_mappings: 文本映射配置                                   │
└─────────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────────┐
│                     Workspace 级别配置                           │
│  (文件存储，与工作空间绑定)                                       │
│  - configs.json: 主配置文件                                      │
│  - templates.json: 模板配置                                      │
│  - items.json: 事项数据                                          │
│  - 数据库键值对: 自动标签规则等                                   │
└─────────────────────────────────────────────────────────────────┘
```

### 2.2 层级说明

| 层级 | 存储方式 | 生命周期 | 适用场景 |
|------|----------|----------|----------|
| 进程级别 | 内存 | 进程运行期间 | 临时状态、缓存数据 |
| App 级别 | 数据库 | 永久存储 | 跨工作空间共享配置 |
| Workspace 级别 | 文件/数据库 | 永久存储 | 工作空间特定配置 |

## 3. 进程级别配置

### 3.1 配置项列表

| 配置项 | 类型 | 说明 | 源文件 |
|--------|------|------|--------|
| current_workspace | WorkspaceContext | 当前工作空间上下文 | CliApp-ext.kt |
| currentWorkspaceDataRepository | WorkspaceDataRepository | 当前工作空间数据仓库 | CliApp-ext.kt |
| currentCmdPrefix | String? | 当前命令前缀 | globals.kt |

### 3.2 访问方式

```kotlin
// 获取当前工作空间
val workspace = app.processData.getCurrentWorkspaceContext()

// 更新当前工作空间
app.processData.updateCurrentWorkspaceContext(workspace)

// 获取/设置命令前缀
currentCmdPrefix = "todo"
val prefix = currentCmdPrefix
```

### 5.3 访问方式

#### 5.3.1 通过便捷对象访问

```kotlin
// Window 配置
Configs.window.isEnable  // 获取窗口模式是否开启
Configs.window.isEnable = false  // 设置窗口模式

// Show 配置
Configs.show.needShowId  // 是否显示 ID
Configs.show.needShowStatus  // 是否显示状态
Configs.show.needShowDone  // 是否显示已完成事项
Configs.show.needShowDeleted  // 是否显示已删除事项
Configs.show.needShowOwner  // 是否显示负责人
Configs.show.needShowLabel  // 是否显示标签
Configs.show.useAlignMode  // 是否使用对齐模式
Configs.show.needShowDeadline  // 是否显示截止时间
Configs.show.needShowComment  // 是否显示备注
Configs.show.needShowCommentSubscript  // 是否显示备注下标

// Show.CommentStyle 配置
Configs.show.commentStyle.getTextColor()  // 获取备注文字颜色
Configs.show.commentStyle.setTextColor("255,0,0")  // 设置备注文字颜色
Configs.show.commentStyle.getBackgroundColor()  // 获取备注背景颜色
Configs.show.commentStyle.setBackgroundColor("255,255,255")  // 设置备注背景颜色

// Show.Status 配置
Configs.show.status.get("new")  // 获取状态图标

// Show.Icon 配置
Configs.show.icon.get("owner")  // 获取负责人图标

// Launch 配置
Configs.launch.needShowOnLaunch  // 启动时是否自动展示
Configs.launch.needShowOnLaunch = false  // 设置启动时不自动展示

// Focus 配置
Focus.id  // 当前聚焦事项 ID
```

#### 5.3.2 通过 WorkspaceContext 访问

```kotlin
// 保存配置
workspace.saveConfig("key", "value")

// 查询配置
val value = workspace.queryConfig("key", "default")

// 获取模板配置
val templates = workspace.templates()

// 更新模板配置
workspace.updateTemplates(templates)

// 获取当前样式名称
val styleName = workspace.getCurrentStyleName()

// 设置当前样式名称
workspace.setCurrentStyleName("dark")

// 获取聚焦 ID
val focusId = workspace.getFocusId()

// 设置聚焦 ID
workspace.setFocusId("item-id")

// 获取快速模式状态
val isQuick = workspace.isQuickMode()

// 设置快速模式
workspace.setQuickMode(true)
```

## 8. 命令行配置操作

### 8.1 config 命令

```bash
# 查看当前配置
todo config -s

# 编辑配置
todo config -e

# 查看帮助
todo config -h
```

### 8.2 style 命令

```bash
# 列出所有样式
todo style --list

# 选择样式
todo style --choose

# 创建样式
todo style --create

# 查看帮助
todo style -h
```

### 8.3 text_mapping 命令

```bash
# 列出所有映射
todo text_mapping -l

# 添加映射
todo text_mapping --add "原文本" "替换文本"

# 删除映射
todo text_mapping -d "原文本"

# 查看帮助
todo text_mapping -h
```

### 8.4 cmd-prefix 命令

```bash
# 设置命令前缀
todo cmd-prefix --set "prefix"

# 清除命令前缀
todo cmd-prefix --clear

# 查看帮助
todo cmd-prefix -h
```
